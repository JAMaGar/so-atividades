# Atividades — Sistemas Operacionais · Fatec São Paulo

Páginas das atividades das aulas 2 a 7 da disciplina de Sistemas Operacionais (CST em Análise e Desenvolvimento de Sistemas), Prof. Me. José Augusto Martins Garcia.

- **Alunos:** abram a página principal, entrem com o RM e a senha criada no primeiro acesso e escolham a aula.
- **Professor:** `professor.html`.

Este repositório tem só as páginas. As entregas, a correção e os gabaritos ficam num serviço privado do professor e não estão aqui.

`pyodide/` é uma cópia sem alterações do [Pyodide](https://github.com/pyodide/pyodide) 0.27 (licença MPL-2.0), usada só pelo painel do professor.
